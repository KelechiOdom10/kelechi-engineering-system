# Sources and adaptation notes

Kelechi Mode is an original Codex-native workflow inspired by ideas from Cursor's pstack and Flavio Copes's analysis. It is adapted rather than vendored: current Codex skills remain the specialists, current authorization rules are preserved, and shared-tree delegation is deliberately constrained.

- Cursor pstack: <https://github.com/cursor/plugins/tree/main/pstack>
- Flavio Copes, pstack deep dive: <https://flaviocopes.com/pstack/>
- Michael Denyer's Claude port and Codex tool mapping: <https://github.com/michael-denyer/pstack-claude>
- Codex plugin documentation: <https://learn.chatgpt.com/docs/build-plugins>
- Codex skill documentation: <https://learn.chatgpt.com/docs/build-skills>
