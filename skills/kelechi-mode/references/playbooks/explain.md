# Explain

1. Resolve what kind of explanation is needed: `how` means current behavior; `why` may require history; `teach` usually needs both.
2. Read the smallest set of authoritative current sources. Use historical context as explanation, not proof of current behavior.
3. Build a concrete mental model from entry point through important state transitions and outputs.
4. Separate verified facts from inference and link claims to sources or local files when useful.
5. Match the reader's altitude and lead with the answer. Do not change code unless separately requested.
