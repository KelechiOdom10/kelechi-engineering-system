# Autonomous

1. Translate the request into an explicit terminal predicate and observable checks. If none can be inferred safely, state the narrow assumption before proceeding.
2. Select the ordinary route that performs the work; autonomy changes persistence, not engineering standards or authorization.
3. Keep a concise decision trail and provide progress during long-running work.
4. Continue through reversible, in-scope steps and recover from ordinary failures using evidence.
5. Stop at external, destructive, irreversible, or materially broader actions that lack permission. Never interpret autonomy as permission to merge, deploy, mutate production, or contact people.
6. Finish only when the terminal predicate is actually satisfied; otherwise report the precise blocker and completed evidence.
