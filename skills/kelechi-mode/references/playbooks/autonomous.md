# Autonomous

1. Turn the request into a terminal condition with observable checks. If none can be inferred safely, state the narrow assumption and proceed.
2. Select the ordinary route that does the work. Autonomy changes persistence, not standards or authority.
3. Keep a decision trail in `.kelechi/decisions.md`: each non-obvious choice, the evidence, and the one word that would reverse it. Give progress updates during long runs.
4. Continue through reversible, in-scope steps and recover from ordinary failures using evidence.
5. Stop at any action the authority table marks ask or always ask. Record it as a blocker and keep working on everything else.
6. Finish only when the terminal condition holds. Otherwise report the precise blocker and the evidence gathered so far.
