# Pause

1. Reach an atomic boundary: leave no half-applied edit hidden in the tree. Commit work in progress on the feature branch when that is cleaner than a dirty tree.
2. Write `.kelechi/handoff-<topic>.md` with provenance frontmatter (see `working-state.md`): objective, current state, verified evidence, decisions and why, changed files, validation run, remaining work, and the exact next action.
3. Include the branch, PR, ticket, and command references needed to resume. Redact secrets and personal data.
4. Keep the handoff local. Commit, push, or post it only within the authority table.
