# Pause

1. Reach an atomic boundary when possible; do not conceal a half-applied edit.
2. Capture the objective, current state, verified evidence, decisions, changed files, validation, remaining work, and exact next action.
3. Include branch, diff, PR, ticket, or task references needed to resume. Redact secrets and sensitive data.
4. Use the `handoff` skill when a durable handoff artifact is requested.
5. Do not commit, push, or post the handoff externally unless authorized.
